# Loan discovery sources (verified 2026-10-15)

Only the two exact official URLs below are in the crawler allowlist. Both returned HTTP 200 with public HTML during a live local run on 2026-10-15. Their `robots.txt` files were retrieved first and permitted these paths for the workflow's user agent. The crawler normally makes one robots request and one page request per source per run, with a one-second pause between them, bounded retries, no redirects, and a daily schedule. Page layout and site policies can change; review them before a long-lived deployment. This is not a license or legal opinion.

The product pages are marketing/eligibility summaries, not underwriting decisions. The source text and its SHA-256 are retained with each version. The sample CSV does not specify an income currency; even an INR product cannot be automatically matched to a user with unknown income currency. Conditional thresholds and unquantified criteria remain `UNKNOWN`, not zero or passing. Synthetic test HTML under `tests/fixtures/sources/` is deliberately separate from live evidence.

Robots and page checks were performed on the final HTTPS hosts; redirecting legacy URLs are not crawled. The URLs are compiled into `services/discovery/sources.py`, not accepted from API callers. If a source blocks access, changes its layout, or revises its terms, the run records a source failure without replacing its previous product version. The source list should be reviewed periodically rather than expanded automatically.
